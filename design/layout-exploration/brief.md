# MyWhoosh 中文管理器 · 全新布局选型

本轮目标：承接上轮十套主题截图，把“同布局换色”改为十套结构、导航、主行动和视觉语言均不同的界面候选。用户允许全部重构，不要求继承原仪表盘布局。

范围：十张原生 Windows 绘图渲染的 UI 候选 PNG；不改当前正式软件代码、不安装补丁、不修改游戏配置、不发布版本。候选属于设计预览，不声称交互功能或端到端验收完成。

每张保留：检查与安装汉化、回退原版、游戏窗口尺寸、游戏置顶、备份状态和帮助入口。危险操作（恢复）与主要安装按钮区分层级。面向小白，状态用中文清楚解释，原技术账本只在高级入口。

展示数据均为示例：版本6.2.3.0，2060课程等，仅用于对比排版；图片底部逐张标明“界面方案预览 · 示例状态 · 尚未接入实际操作”。不会显示用户账号、安装路径、游戏存档或代理IP。

字体：中文信息使用本机 Windows 微软雅黑，技术标签局部使用Consolas，编辑型大标题可用宋体。字体不复制或分发；仅渲染位图。

十个独立方向：
1. 石墨工作台：窄侧栏，不等尺寸bento，中部突出已汉化状态，右部窗口控制，底部恢复卡。
2. 云白极简：顶部导航，开放大字排版，列表式安全与状态信息，无常规指标卡墙。
3. 竞速座舱：侧边细轨、斜切品牌块，荧光黄绿对深蓝，中央主动作，下部设备式窗口控制。
4. 小白向导：左侧三步流程，右侧单步安装语言选择与大按钮，窗口功能放在底部可选条。
5. 鼠尾草桌面：暖白加墨绿，横向轻导航，柔和的主工作区，窗口与恢复并列但主次明确。
6. 瑞士排版：黑白、强调黄、开放网格和大字编号，不同字级而非卡片承载主要层级。
7. 工程控制台：深色、青绿、细边框、多窗格，左资源树，中间检查结果，下方日志，右窗口检查器。
8. 轻量悬浮舱：更小的应用窗口，短工具栏、两条主要动作，下部置顶与尺寸捷径，冷蓝透明感但文字不透明。
9. 编辑式修复中心：酒红与暖白，衬线大标题，纵向备份时间线，恢复与汉化明确并列，右控制台。
10. 大字无障碍：高对比浅色、宽大按钮、少技术术语，横向三任务分区，优先“改中文/恢复英文/小窗置顶”。

验收：十张不能只换配色；每张有独立结构；所有中文可读，不裁切按钮文案；至少18px辅助字；主操作与恢复有明确层级；完整位图尺寸与记录匹配；使用本机确定性绘制，不调用游戏操作。先看全套对比总览，再逐张查看原图。
