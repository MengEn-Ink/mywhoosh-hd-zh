# main 开发分支修复：交互、课程增补与增量事务

本轮仅提交源码，不改变 release-version.txt，不覆盖或重新发布 v0.2.0。原游戏安装状态不被本轮测试修改。开发机编译版本仍沿用仓库 0.2.0，不把未发行的开发包当成新正式版本。

## 修复内容

### 操作与状态

- 总览首次按钮改为「检查中文状态」，只读游戏检查；检查成功且有待写入时，明确显示「安装 / 更新中文」，由独立安装动作和确认继续。
- 无本工具账本显示「无本工具记录」，不再断言未汉化。有效账本显示有本工具备份，不用账本状态代替当前课程中文状态。
- 显示检测到的实际版本、已中文数量（AlreadyChinese）、配置预设与真实窗口客户区尺寸；置顶偏好与读回 WS_EX_TOPMOST 分开。
- 时间来自新账本首次创建字段，增量或置顶不改首次时间；旧账本缺字段明确时间未知，不用 mtime 冒充。
- 选择窗口预设保持待应用草稿；出错或写入后清除过期课程检查统计。
- 增加内置上手帮助和中英术语；不复制第三方指南截图。

### 三条课程

新增独立 courses-supplement.json，不修改原 courses.json、categories.json 和界面 PAK。补充 15min Varied Tempo #1 三个精确原文键（CRLF、LF、无段落换行），中文说明保留第3区、15分钟、目标踏频及完整英文原文。原始训练参数、收藏、时长、功率和区间不改。

资源缓存版本为 v1.1.0-r1；四项资源均固定 SHA-256，原三项哈希保持不变。增补字典 SHA-256：F5BFB441CFFB72D082396A1E84D3C6AFC5E6283F3D14473B57E3D5C4C9357CB9。高级导入仍支持原上游三项包，独立增补从当前程序释放并核验。

### 增量与回退

- active 汇总账本仍为 Schema 1，兼容既有 v0.2.0 账本；每个文件首次原始备份不覆盖。
- 增量先准备本批当前文件、前后元数据及唯一 Revision，pending 批次持久化后逐文件核验写入，最后提交汇总账本。
- 当前批失败或进程中断只回滚该批；已提交旧批不撤销。元数据已经提交但尚未删除 pending 时，重启识别为已提交，不误回滚。
- 同一路径重新下载相同已知原文可增量翻译；同路径新语义或未知课程拒绝猜译。冲突保留现场，不强行覆写。
- 回退前比较非文字字段；增量期间收藏变化不再被整文件恢复抹掉。
- 修复首次 LegacyMigration 被 Journal 默认 prepared 状态误拦截，导入前后均核验账本、旧备份与字典；备份用唯一名称避免重迁覆盖。
- 窗口应用和窗口恢复复用持久多文件批次；失败/中断回滚，后续改过的窗口配置与未知键不强行覆盖。
- 安装兼容校验仍完整保留；同包族游戏版本更新后的安全撤销由 RestoreTarget 按账本核验，不跳过目标归属。

## 验证范围

子进程测试在全新临时目录中于写入边界直接 Environment.Exit(86)，不会触碰真实游戏：首次安装、增量批、已提交但未删除 pending、窗口应用、窗口恢复五类均由父进程验证恢复。

GUI 自验收使用真实 OnMouseUp 命中和 MainForm.OnAction/Execute 分发，但使用隔离测试后端，不写真实游戏或 AppData：检查不安装、明确安装、账本状态、已中文与可匹配区分、真实版本/置顶读数呈现、预设草稿、忙态禁用、四页导航、不支持构建和帮助入口。

## 边界

本轮未在真实游戏执行安装、回退、拖边缩放或普通窗口覆盖对抗；未更改比赛、阻力、成绩同步、账号及硬件，未运行上游 DLL。实际任意游戏窗口缩放及长期置顶仍需要单独真机验收，不声明已解决该限制。相同路径课程语义变化会保守拒绝；批次冲突需保留现场处理，不自动删除未知内容。
