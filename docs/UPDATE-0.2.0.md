# 0.2.0 更新说明（本地已验证）

## 新增
- 游戏窗口：默认不再独占全屏，可设为 1280×720 等小窗；保留标准 Windows 边框，可拖动标题栏移动。
- 窗口置顶：管理器运行期间每 2.5 秒把 MyWhoosh 游戏窗口压回最前，其他置顶软件无法遮挡；关闭开关即停止守护。
- 汉化资源内置：课程字典、分类字典与界面 PAK 已嵌入程序，首次运行自动校验并释放，无需再导入第三方 ZIP。
- 完整原版回退：可核验并导入旧版安装器的恢复账本，统一回退课程、分类和界面补丁；恢复保留后续收藏与未知文字改动。
- 界面按深色仪表盘重做：左侧导航 + 指标卡片，顺序为标题→指标→操作→上手→日志；窗口可自由缩放（最小 960×660）。

## 小白流程
1. 解压运行 `MyWhooshZH.exe`（无需安装 .NET/Python）。
2. 首次自动释放内置资源并检查；退出游戏后点「安装 / 更新」。
3. 「游戏窗口」页勾选置顶，设定宽高，点「应用窗口设置」，再启动游戏。

## 实测结果
- 42 项自动化回归全部通过（含窗口配置写入/精确回退/保留无关改动、旧账本迁移、回退哈希复原、ZIP 路径穿越防护等）。
- 真实游戏：2058 条旧恢复记录成功迁移；执行过一次完整回退（2062 文件恢复、零跳过、已汉化课程 0），再完整重新汉化。
- 实际启动游戏为 1280×720 标准窗口，中文界面正常，标题栏可拖动。
- 置顶守护为周期重设 API，需管理器保持运行；游戏独占全屏时置顶无效，故必须先切窗口模式。

## 边界
- 仅适配实测构建 6.2.3.0（PackageFamilyName 固定、主资源哈希白名单）；未知版本拒绝安装。
- 窗口缩放受游戏自身限制，管理器只写配置并置顶窗口，不注入游戏进程、不改 EXE。
- 内置资源随程序分发，来源为社区汉化补丁；再分发授权未确认，仓库保持私有，请勿公开传播。
