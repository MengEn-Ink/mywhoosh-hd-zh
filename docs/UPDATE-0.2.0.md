# v0.2.0 更新说明 · 竞速座舱内置版

## 新增

- 使用用户选定的「03 竞速座舱」重写原生 GUI：深海军蓝 / 荧光黄 / 切角面板，总览、汉化、窗口、恢复四页。
- 页面状态来自真实检查、窗口配置、备份和资源校验，不使用设计稿示例统计。
- 管理器最小尺寸 960×720；布局验收覆盖 1280×860、1100×760、960×720。
- 支持应用游戏窗口模式和尺寸预设，关闭默认独占全屏配置；标准标题栏移动可用，边缘缩放受游戏自身限制。
- 每 2.5 秒置顶守护，可随时关闭；保持管理器运行，游戏需为窗口模式。不保证压过其他置顶程序、独占全屏或安全桌面。
- 三项社区汉化资源内嵌，自动校验释放，不需另行导入 ZIP；不执行第三方脚本或 DLL。
- 支持已核验的旧回退账本迁移、按记录恢复英文，保留收藏及无关配置。
- 增加内嵌资源首次释放、有效缓存幂等、损坏缓存修复回归；发行包验证 CLI 和六张 GUI 布局，再生成 SHA-256 校验和。

## 已有测试证据

基础 42 项、隔离集成总计 43 项通过；扫描 2063 / 匹配 2060 / 未匹配 3。该次隔离测试源为已有中文缓存，变更和恢复 1 个 PAK，原有缓存哈希全部一致，不将其描述成新翻译 2060 个文件。

本机真实游戏置顶往返：原值 false → 置顶 true → 恢复原值成功。发布自验收计数见 tests.json / gui-layout.json；真机游戏功能不由无游戏 CI 证明。

## 使用

完整解压运行包，双击 MyWhooshZH.exe。先加载游戏训练列表并退出，点「检查并安装中文」。窗口页应用预设尺寸，再启动游戏；需要置顶时让助手保持运行。恢复前退出游戏，保留 AppData 的备份。
