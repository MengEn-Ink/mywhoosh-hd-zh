# 新手使用指南

## 下载哪个

下载 Releases 中名称带 `win-x64.zip` 的运行包，不是 Source code。解压到自己有写入权限的文件夹，再双击 MyWhooshZH.exe。不需要管理员权限，不要用别人的管理员账户。

资源包需要另行从上游取得：
https://github.com/GourmetGodTangNiu/MyWhoosh-Chinese-Patch

选择 MyWhoosh_HD_6.2.3.0_Chinese_Package_v1.1.0.zip。不要选择 EXE，导入器不运行其中的任何代码；只认可固定 SHA-256 的三个数据文件。

## 首次使用

- 点“导入汉化资源”，选择上游 ZIP。
- 打开 MyWhoosh HD，在训练列表等待课程出现，完全退出游戏。
- 点“检查安装状态”：受支持身份、资源哈希和扫描统计必须正常。
- 点“安装 / 更新”，查看真实结果。匹配数不等于全游戏翻译覆盖率。
- 重新打开游戏确认中文。部分动态项目和未匹配课程可能仍为英文。

## 几种状态怎么理解

- imported：资源导入成功，还没有改游戏。
- unmanaged：本工具没有旧安装的备份；可能尚未装，也可能已由其他安装器安装。
- unchanged：已匹配内容无需变更，不能据此声称本工具拥有恢复记录。
- installed：写入与校验完成，仍需查看游戏。
- restored：已还原本工具管理的内容。
- conflict：检测到后续修改，保留冲突文件，不强行覆盖。
- prepared：上次写入被中断，下次操作会先尝试安全回滚，不能直接叠加安装。

## 恢复英文

完全退出游戏，点击“恢复本工具安装”。只恢复本工具的账本记录。后续收藏等非文字字段保留；用户另改的译文保留并提示冲突。没有账本时不会删除旧汉化 PAK。

如果此前使用的是旧版一键汉化，先用旧版的“一键恢复英文.cmd”，不能拿本工具的空账本替代它。

## 更新和故障

游戏更新、包名或主资源哈希变化时停止安装。这是保护，不是建议关掉校验。请把诊断输出中版本、包名及错误信息提供维护者；分享日志前删除个人路径、账号和本地文件内容。

日志和资源在 `%LOCALAPPDATA%\MyWhooshHdZh`；备份在其 `state` 子目录。不要清理备份后又期望自动恢复。不要将整个目录上传 GitHub。

不支持自动更改 WindowsApps 权限，不修改主资源，不处理反作弊、资源加密、比赛或账户功能。没有证据时不会承诺所有未来版本通用。
