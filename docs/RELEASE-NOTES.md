# v0.3.1 · 卡顿与浮窗同步修复

下载 `mywhoosh-hd-zh-0.3.1-win-x64-setup.exe`。先在托盘退出旧助手，再安装到原助手目录；汉化备份、资源与偏好保留，不需要重新安装汉化。安装不自动改游戏、不默认开机自启。

## 这次修复

- 初始状态与操作后全量备份校验、商店包查询改为后台执行。界面和浮窗不再等待大量备份核验才响应；完整校验仍保留，不用缓存替代写入/恢复安全门禁。
- 窗口与置顶操作使用返回结果更新对应状态，不再顺带重验所有汉化备份。
- 运行状态改为500ms轻量单飞刷新，缓存并验证游戏句柄；缺失窗口限频重查。没有变化不重绘，不重复对已置顶窗口发置顶命令。Windows置顶调用采用异步窗口定位，不等待游戏窗口线程处理。
- 显式置顶与守护串行、过期状态丢弃，避免旧刷新覆盖最新操作。保留真实置顶读回，异步命令提交不冒称已成功生效。
- 浮窗选项与主面板尺寸草稿同步。置顶不抹掉尚未应用的尺寸；下拉展开时不抢选项。隐藏主面板时确认框以浮窗为父窗口，托盘操作先确保确认入口可见，错误不再静默。
- 加入6项专门响应性回归：慢初始后端期间UI计时器仍响应、置顶不调用全量摘要且保留草稿、运行态单飞和主/浮窗一致、过期结果保护、隐藏错误反馈、取消确认不写入。

## 诊断依据与边界

用户安装的v0.3.0进程路径为 `D:\app\MyWhooshHdZh`。本机只读计时：商店查询约1303ms，汉化账本全量摘要约5562ms；旧版这两项在UI线程执行。资源校验约49ms、窗口配置读取约13ms、10次窗口扫描约63ms。一次测量不代表所有机器稳定耗时。系统当次CPU约2%、可用内存约14.6GiB；助手10秒静置采样单核CPU为0%，不能据此否定点击时卡顿。

0.3.0功能/布局门禁未覆盖慢后端UI消息循环，导致漏检；新响应性测试补上该缺口。隔离按钮响应时间不是生产安全校验总耗时，置顶仍需商店身份和主PAK完整校验，重操作仍可能等待，但UI不应被阻塞。

83项核心、13主GUI交互、25图布局、8浮窗、6响应性测试与隔离安装/升级/重装/卸载门禁均由构建执行；最终以本版实际CI、performance-tests.json和release-evidence.json为准。发布后ZIP、Setup回下载核对哈希，并复跑资源/GUI/浮窗/响应性测试。

本版针对助手刷新，不负责游戏账号/成绩/功率网络同步。用户未明确“同步慢”的游戏侧范围，不能宣称网络同步已解决。未自动安装到用户电脑、未修改游戏配置/备份、未关闭安全软件。真实游戏拖边、长期置顶、物理DPI/真实托盘第二生产进程仍未穷举。仅支持已验证Windows x64商店6.2.3.0；未签名，核对来源和SHA256SUMS，旧版本保留。
