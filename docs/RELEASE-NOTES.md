# v0.2.1 · 稳定性与增量更新版

下载 **mywhoosh-hd-zh-0.2.1-win-x64.zip**，完整解压后双击 **MyWhooshZH.exe**，不要选择 Source code 作为运行包。汉化资源和 .NET 运行时内置，无需 Python、Node、SDK 或第三方窗口工具。

## 相比 v0.2.0

- 先「检查中文状态」，再「安装 / 更新中文」，检查不会自动安装。
- 准确区分实际版本、已中文数量、可匹配数量、汉化备份和窗口备份；置顶偏好不冒充实际置顶。
- 独立精确补齐 15min Varied Tempo #1 的三个原文变体，保留完整英文与训练参数；原三项上游资源字节不变。
- 增量更新保留首次备份；失败或进程中断只撤销当前未完成批次。已提交但未清掉 pending 的批次不会被误回滚。
- 新增「处理中断记录」和「处理窗口中断」，与恢复全部英文或原始窗口设置明确分开。未知冲突保留现场。
- 恢复保留增量期间新增的收藏等非文字状态；修复首次旧账本导入和重复备份问题。
- 修正 CLI --topmost 参数与非法尾随参数；修正窗口结果覆盖汉化备份状态。
- 长提示/日志有限空间省略但可查看全文；修复窄页步骤挤压、高 DPI 标题裁切；操作进行中暂不关闭，计时器随窗体释放。
- 发布门禁增加两个自包含 EXE 的资源首次释放/有效缓存/损坏修复检查。

## 三步上手

1. 在游戏中加载训练列表，完全退出游戏。
2. 打开新助手，点「检查中文状态」，有待写入再点「安装 / 更新中文」。
3. 需要小窗时选择尺寸、应用，再打开游戏；置顶时保持助手运行。

升级请解压到新目录，用新 EXE，保留 `%LOCALAPPDATA%\MyWhooshHdZh\state`。旧 v0.2.0 标签和包不覆盖。
