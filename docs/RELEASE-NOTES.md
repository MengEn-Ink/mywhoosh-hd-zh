# v0.3.0 · 标准安装与快捷浮窗版

普通用户下载 **mywhoosh-hd-zh-0.3.0-win-x64-setup.exe**，双击按向导安装到硬盘。默认当前Windows用户，目录 `%LOCALAPPDATA%\Programs\MyWhooshHdZh`，可选择独立目录，无需管理员权限。仍提供便携ZIP，不要下载Source code当运行包。

## 新增

- 标准安装、版本升级元数据、系统已安装应用卸载入口。
- 桌面/开始菜单提供「MyWhoosh 中文助手」「MyWhoosh 快捷浮窗」快捷图标。
- 可拖动桌面浮窗：实际置顶状态、置顶开关、窗口尺寸选择与确认应用、打开主面板、收起托盘。
- 托盘菜单：打开主面板/浮窗、游戏置顶、预设尺寸、明确退出。
- 关闭面板仅收起，退出托盘才停止助手和置顶守护。重复打开快捷方式激活同一会话实例。
- 自有抽象多尺寸ICO用于EXE、托盘、快捷方式和安装程序。

安装本身不汉化、不改游戏窗口、不加开机自启。升级/卸载保留当前账户AppData汉化备份、资源和偏好；卸载不自动回英文，需要回英文请先在助手恢复页操作。升级前从托盘退出，安装程序不会强杀助手。
