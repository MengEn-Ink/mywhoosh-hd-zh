# v0.2.0 · 竞速座舱内置版

把语言、窗口和恢复放在一个原生 Windows 面板里。按用户选定的「03 竞速座舱」重做四个页面，深海军蓝 + 荧光黄 + 切角卡片，按钮使用小白易懂的短句。

## 下载哪个

下载 **mywhoosh-hd-zh-0.2.0-win-x64.zip**，完整解压，双击 **MyWhooshZH.exe**。不要下载 Source code 当运行包。

汉化资源与 .NET 运行时已内置；无需另找汉化 ZIP，无需安装 Python、Node、SDK、.NET 或第三方置顶工具。仓库可见性保持不变，私有仓库下载需要已有访问权限。

## 这版新增

- **真实竞速座舱**：总览 / 汉化 / 窗口 / 恢复四页，显示实际检查统计、备份和资源状态；管理器支持拖动缩放，验收覆盖三种尺寸。
- **小窗启动**：选择尺寸后应用窗口配置，使用标准窗口模式，避免默认独占全屏；可拖动标题栏，边缘缩放受游戏自身支持限制。
- **始终置顶**：管理器保持运行时每 2.5 秒置顶游戏窗口，可一键关闭；不保证压过其他置顶程序、全屏应用或系统安全桌面。
- **汉化资源内置**：课程、分类字典和界面 PAK 自动释放并核验 SHA-256，不执行上游脚本、EXE 或 DLL。
- **回退英文**：按备份账本还原本工具的修改，保留收藏、训练参数和未授权覆盖的后续改动；可核验导入旧版回退记录。
- **发布门禁**：基础回归 + 内置资源释放/修复测试 + 发布后 CLI 冒烟 + 六张 GUI 布局自检，生成校验和及可回读资产证据。

## 三步上手

1. 在游戏里加载训练列表，完全退出游戏。
2. 打开中文助手，点「检查并安装中文」。
3. 在窗口页应用尺寸，再启动游戏；置顶时保持助手运行。

恢复英文前先退出游戏。不要删除 `%LOCALAPPDATA%\MyWhooshHdZh\state` 的备份。

## 验证和兼容性

- 仅支持已验证的 Windows x64 商店构建 MyWhoosh HD 6.2.3.0：`MyWhooshTechnologyService.644173E064ED2`；未知身份或主资源哈希变化会拒绝安装。
- 发布前已有 42 项基础回归与隔离集成总计 43 项通过。本次另加入 3 项内置资源回归，实际发布计数以 `tests.json` 为准。
- 已验证真实游戏置顶位从 false 变为 true，再成功恢复原值；未进行恶意同用户进程对抗。
- 6 张 GUI 截图文字越界告警为 0，机械检测不能替代人工排版或全游戏页面验证。
- 隔离缓存扫描 2063 / 匹配 2060 / 未匹配 3，恢复后原缓存哈希一致；该次使用已有中文缓存，安装和恢复变更 1 个 PAK，不冒称重新翻译了 2060 个文件。
- 未覆盖比赛、阻力硬件、成绩上传、长期运行、ARM64 与未来版本。游戏任意边缘拖动缩放未作为已完成真机结论。

资源来自社区项目 MyWhoosh-Chinese-Patch v1.1.0。发布者确认已获三项资源随本项目下载包内置分发的授权；保留来源及字体许可，不授予使用者无限制再分发权。程序不修改游戏主 PAK、不更改 WindowsApps 权限、不注入游戏。
