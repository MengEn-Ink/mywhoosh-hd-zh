# 0.1.1 预发布

在 0.1.0 基础上增加中文检查摘要、统一版本显示与发行资产回读校验；保留完整原生安装/恢复流程。

MyWhoosh HD 中文管理器首个原生 Windows x64 版本。

- WinForms GUI 与 CLI 共享 .NET 10 核心。
- 精确构建白名单、SHA-256 资源检查、UTF-8/UTF-16 课程解码。
- 原子写入、操作锁、备份与事务恢复、保留后续收藏/文字冲突。
- 安装器不会执行上游 ZIP 内的脚本、EXE 或 DLL。
- 运行包自包含 .NET，无需安装开发环境。

资源包不随本版本再分发；请按 QUICKSTART 从上游获取后导入。仅支持验证过的 6.2.3.0 构建。已有旧版汉化恢复由原安装器负责。

预发布不承诺全页面、比赛、阻力、成绩上传、未来游戏版本兼容。详见 docs/VALIDATION.md 与 SECURITY.md。
